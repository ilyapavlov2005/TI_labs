# РЕПОЗИТОРИЙ: Лабораторные работы по курсу «Теория информации»
О проекте
Данный репозиторий содержит выполненные лабораторные работы по дисциплине «Теория информации». Все программы реализованы на языке Java с использованием графического интерфейса Swing.

Каждая лабораторная работа представляет собой законченное приложение с удобным интерфейсом, проверкой входных данных и наглядным выводом результатов.

# Лабораторная работа №1: Простейшие алгоритмы шифрования (Вариант 3)
Описание
Реализация шифратора и дешифратора на основе метода Виженера — многоалфавитного шифра подстановки. Шифр Виженера использует последовательность ключей для циклического сдвига символов исходного текста.

Цель
Изучить принципы симметричного шифрования и работу многоалфавитных шифров подстановки.

Функциональность
Ввод ключевого слова для шифрования

Поддержка русского алфавита (33 буквы)

Работа с текстовыми файлами

Шифрование по таблице Виженера

Дешифрование с использованием того же ключа

Вывод исходного, зашифрованного и расшифрованного текстов

Используемые алгоритмы
🔹 Таблица Виженера

🔹 Циклическое повторение ключа

🔹 Многоалфавитная подстановка

# Лабораторная работа №2: Криптосистема Рабина
Описание
Реализация криптосистемы Рабина — асимметричного алгоритма шифрования, стойкость которого основана на сложности факторизации больших чисел и извлечения квадратного корня по модулю составного числа.

🎯 Цель
Изучить принципы асимметричного шифрования и работу криптосистемы Рабина.

⚙️ Функциональность
Генерация ключей (p, q, b) с проверкой условий

Шифрование любых файлов (текст, изображения, видео)

Дешифрование с выбором правильного корня

Сохранение шифротекста в бинарном формате

Вывод зашифрованных данных в 10-й системе счисления

Проверка параметров на корректность

Сохранение шифротекста в PNG-изображение

Используемые алгоритмы
🔹 Расширенный алгоритм Евклида (нахождение обратных элементов)

🔹 Быстрое возведение в степень по модулю

🔹 Китайская теорема об остатках

# Лабораторная работа №3: Потоковое шифрование на основе LFSR
Описание
Реализация потокового шифра на основе регистра сдвига с линейной обратной связью (LFSR) степени 26. Программа шифрует и дешифрует любые файлы, генерируя ключевой поток той же длины, что и исходный файл.

Цель
Изучить принципы потокового шифрования и работу генераторов псевдослучайных последовательностей на основе LFSR.

⚙️ Функциональность
Ввод начального состояния регистра (26 бит)

Генерация ключевого потока с помощью LFSR

Шифрование/дешифрование любых файлов (XOR)

Вывод ключа, исходного и зашифрованного файлов в двоичном виде

Сохранение результата как поток байтов

Фильтрация ввода (только 0 и 1)

Отображение первых 100 бит ключа и 100 бит файлов

Используемые алгоритмы
🔹 Регистр сдвига с линейной обратной связью (LFSR)

🔹 Полином: x²⁶ + x⁸ + x⁷ + x

🔹 Операция XOR для шифрования/дешифрования

# Лабораторная работа №4: Электронная цифровая подпись DSA
Описание
Реализация алгоритма электронной цифровой подписи (ЭЦП) DSA для текстовых файлов. Программа позволяет подписывать файлы и проверять подлинность подписи.

Цель
Изучить принципы работы алгоритмов цифровой подписи и хеширования.

Функциональность
Подписание файла:

Ввод параметров q, p, h, x, k, H₀

Вычисление g = h^((p-1)/q) mod p

Вычисление y = g^x mod p (открытый ключ)

Вычисление хеша по формуле Hᵢ = (Hᵢ₋₁ + Mᵢ)² mod q

Создание подписи (r, s)

Сохранение подписи в конец файла

Проверка подписи:

Ввод публичных параметров q, p, h, g, y, H₀

Извлечение r и s из файла

Восстановление хеша сообщения

Проверка подписи через вычисление v

Вывод результата: верна/неверна

Используемые алгоритмы
🔹 Алгоритм DSA (Digital Signature Algorithm)

🔹 Хеш-функция Hᵢ = (Hᵢ₋₁ + Mᵢ)² mod q

🔹 Быстрое возведение в степень по модулю

🔹 Малая теорема Ферма (обратный элемент)

🔹 Проверка числа на простоту
